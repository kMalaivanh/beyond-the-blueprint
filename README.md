# Beyond the Blueprint

A scroll-driven engineering portfolio about improving physical, digital, and human systems.

## Get started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy

Import this repository at https://vercel.com/new and select the Vite preset. The build command is `npm run build` and the output folder is `dist`.

## Confidentiality

The electrical harness and technical systems are illustrative, not Grand Design source drawings or confidential production data. This is the first prototype, not the final 3D showcase.
